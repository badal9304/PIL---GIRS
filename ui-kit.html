Button

One primary action per area. Secondary for the rest. Small (32px) inside tables, toolbars and panels; default (36px) in page headers and dialog footers.

  • Do name the outcome: “Generate 935”, not “Submit”.
  • Do keep a disabled button visible and say why next to it.
  • Don’t put two primary buttons side by side.

Classes .btn .btn-primary .btn-sm .btn-icon .lnk

Text field

Label above, 36px high. Grey means read-only (cannot be changed on this screen). Errors show a red border and a short reason under the field.

Enter a unit price.

Classes .input · read-only: readonly attribute · error: .bad + aria-invalid

Select

For a short, fixed list (up to ~10 options). For long or searchable lists use the Combobox.

Classes .select inside a wrapper with the chevron icon

Combobox (type-ahead)

Search by name or code; arrow keys move, Enter picks, Esc closes. Used for customers, charges, ports, vessels.

Toast

Short confirmation after an action. Disappears on its own; never the only place an error is shown.

Filter chip

Quick filters over a list, with a count. One active at a time unless the label says otherwise.
